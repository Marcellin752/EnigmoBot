# Documentation

Complete guides to set up and run the EnigmoBot Discord bot from scratch.

## Guides

| Guide | Description |
|---|---|
| [Prerequisites](PREREQUISITES.md) | What you need before starting |
| [Discord Bot Setup](DISCORD_SETUP.md) | Create a Discord application and get a bot token |
| [Invite the Bot](INVITE_BOT.md) | Add the bot to your server |
| [Gemini API Setup](GEMINI_SETUP.md) | Get a free Gemini API key |
| [Configuration](CONFIGURATION.md) | Configure the `.env` file |
| [Run the Bot](RUNNING.md) | Launch and verify the bot |

## Recommended order

Follow the guides in the order above: each step builds on the previous one.
A typical first-time setup takes about 15 minutes.
