# Prerequisites

Before setting up the bot, make sure you have the following:

## Accounts

| Requirement | Where to get it |
|---|---|
| A Discord **user account** | [discord.com](https://discord.com/) |
| A server where you have **Manage Server** permission (to invite bots) | Create one in Discord |
| A **Google account** for the Gemini API key | [accounts.google.com](https://accounts.google.com/) |

## Software

- **Python 3.10 or higher**
  - Check your version:
    ```bash
    python3 --version
    ```
  - If missing, download it from [python.org](https://www.python.org/downloads/)
- **Git** (to clone the repository)
  ```bash
  git --version
  ```

## What you will have at the end

At the end of this setup you will have:

1. A Discord application with a **bot token**
2. Your bot **invited** to your server
3. A **Gemini API key**
4. A running bot that responds in Discord

## Estimated time

- Discord bot creation: ~10 minutes
- Gemini API key: ~5 minutes
- Configuration and launch: ~5 minutes
